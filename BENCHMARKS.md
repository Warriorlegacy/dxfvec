# Benchmarks — dxfvec

Measured, reproducible performance numbers for the three conversion engines.

## How to reproduce

```bash
pip install -e ".[dev]"
python benchmarks/run.py
```

This regenerates `benchmarks/results.json` from scratch on your machine. It runs
`engine.convert()` end-to-end on synthetic technical drawings generated by the harness
itself, so there is no external dataset to download.

## Method

| Field | Value |
|---|---|
| What is measured | `engine.convert()` wall time: preprocessing, contour tracing, arc detection, DXF write, QA report |
| What is excluded | process start-up, import time |
| Timing | `time.perf_counter()` |
| Aggregation | median of N runs |
| Repeats | 3 per input/engine |
| Inputs | `small_512` (512×512), `medium_1024` (1024×1024), `large_2048` (2048×2048) |

**Caveat:** these are single-machine measurements on the author's hardware. They are
not a claim about absolute performance on other machines. Re-run to verify — the
results file records the environment it was produced in.

of speed in an interview now traces to a file that can be re-run.
